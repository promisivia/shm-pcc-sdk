# Support

CXL-SDK is maintained as an open-source research project.

- Use [GitHub Issues](https://github.com/promisivia/shm-pcc-sdk/issues) for
  reproducible bugs and focused feature requests.
- Use GitHub Discussions for design questions and general usage help when that
  feature is enabled.
- Follow [`SECURITY.md`](SECURITY.md) for private vulnerability reports.

When requesting help, include the commit, operating system, kernel, compiler,
CMake version, CPU architecture, NUMA/CXL topology, configuration, exact command,
and complete error output. Hardware-specific behavior is difficult to diagnose
without this context.

Commercial support and response-time guarantees are not currently provided.
