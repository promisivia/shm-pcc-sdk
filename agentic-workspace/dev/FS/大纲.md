Title: 新型互联超节点上的文件系统设计

CXL/UB技术构建的超节点正在成为训练推荐等业务的主流选择，本项目将面向超节点新型互联架构，探索如何利用 CXL/UB 的内存池化与缓存一致性等特性，设计一种面向超节点架构的字节寻址文件系统，通过研究硬件感知的数据布局与无锁化的访问路径，我们期望在超节点范围内实现极低延迟的数据共享与高带宽的并发 I/O，为下一代高性能计算与大模型训练提供坚实的存储基座。

### 硬件变化
CXL: 多节点共享内存
UB：每个节点可以借用内存给他人

缓存不一致：节点之间都没有缓存一致性/有原子指令
容错：节点和部分内存一起挂

<关系：下一页讲缓存不一致>

### 挑战：如何设计一个针对缓存不一致、可容错的FS

单机FS → 面向UB的FS <- 分布式FS

单机无法应对容错和缓存不一致
分布式无法利用load/store语义

### 我们的方案（做4--5页？）

基于 LD_PRELOAD/FUSE + BwTree 的 FS 接口

〈画一张架构图〉
底层使用一棵物理B+树，抽象出inode/dentry/data/meta逻辑树，存储key/value对
- inode:<ino, inodevalue>
- dentry:<{parentino,name},{childino,type}>
- data:<{ino,index>,{data}> // 定长逻辑段
- meta:存储 superblock/ino_alloc

BwTree 提供 transaction 接口，来原子地操作元数据
