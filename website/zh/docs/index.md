# CXL-SDK 文档

CXL-SDK 为共享内存与 CXL/UB 系统开发提供可复用的内存管理、并发数据结构、通信和评测组件。

本站按阅读目的分为四个部分：先从概览完成安装并了解项目能力；通过技术博客理解 CXL/UB 与系统设计；在开发者文档中学习如何扩展仓库；需要具体接口时查阅 API Reference。
